## 핵심 사이클

씨앗 상점에서 씨앗 구매 → 괭이로 밭 갈기 → 심기 → 물주기(날씨 대응) → 수확(★1~5 품질) →
포장대에서 **출하 상자**에 담기 → 상자를 들고 **부두의 화물선**까지 운반 → 17:00 출항 때 정산 →
더 좋은 씨앗·스프링클러·영양제·비가림막 구매

## 특징

- **실제 작물 200종**: 적정 기온, 물 요구량, **비 내성**(토마토·딸기·체리는 비에 약하고 벼·미나리는 비를 좋아함),
  서리 내성, 덩굴 지지대, 다년생, 습지 작물. 등급이 높을수록 비싸고 까다로움.
- **기온 기반 계절**: 매일의 기온·일교차·날씨(맑음·흐림·비·폭풍·안개·눈, 장마)로 생장이 결정되고 서리가 내리면 약한 작물이 시듦.
- **시세**: 한꺼번에 많이 팔면 값이 내려가고 매일 회복, 제철이 아니면 비쌈.
- **큰 섬 (240×180 타일)**: 농장, 마을 광장(씨앗방·공방·게시판), 항구, 등대 곶, 강과 다리, 속삭이는 숲,
  **절벽 고원 두 곳**(별빛 언덕·북쪽 숲 능선, 돌계단으로 오르기), **은빛 폭포**, 숲속 야영지, 잊힌 유적,
  언덕 위 정자, 햇살 과수원, 조수 웅덩이, 노을 해변(파라솔·모래성). 들판 곳곳의 **큰 바위**와
  햇빛 방향으로 음영이 진 **완만한 언덕**이 평평한 땅을 깨뜨림.
- **손그림 같은 도트 그래픽**: 진하고 선명한 잔디 패치와 풀포기 도장, 풀이 넘어와 덮인 주황빛 흙길,
  잎 뭉치마다 입체 음영을 준 나무, 쪼갠 통나무 울타리, 기와 한 장씩 그린 지붕.
  건물은 모두 정면만 보지 않음 — **박공면이 앞을 향한 집**, 현관 데크가 있는 **ㄱ자 농가**, 대장간 날개가 붙은 공방.
  **접지감**: 작물은 흙 둔덕에서 자라 나오고, 바위·나무·울타리·건물 밑동은 풀(겨울엔 눈)에 묻혀 있음.
  모든 나무·바위·소품은 개체마다 모양이 다름. 나무·건물 뒤에 서면 반투명해짐.
- **살아 있는 섬**: 주민 5명이 시간표대로 생활 (대화·선물·하트 10단계, 잼·과일주·차·꿀 같은 가공품과 보석에도
  주민마다 다르게 반응 — 좋아하는 재료로 만든 걸 알아봄), 매일 바뀌는 게시판 의뢰,
  계절별 채집물(버섯·조개·바다유리·산딸기·과수원 낙과 등), 나비·갈매기·참새(다가가면 날아감)·잠자리·뛰어오르는 물고기.
- **농장 개간**: 새 농장은 잡초·돌·나뭇가지로 덮여 있음 — 괭이·낫·곡괭이로 치우며 섬유·돌·나무를 얻고, 잡초 속에서 씨앗을 줍기도 함.
- **채석장과 제작**: 북쪽 절벽 아래 옛 광산(동굴 입구·광차 선로·광부 오두막)에서 매일 돌·석탄·구리·철·보석 광맥이 새로 생김.
  집 옆 **작업대**에서 14가지 제작 (저장 상자, 퇴비통, 용광로, 보존 항아리, 술통, 씨앗 제조기, 벌통, 자동 수확기, 스프링클러 등).
- **광산 30층**: 채석장 동굴 아래로 층마다 새로 파인 갱도. 흙빛 갱도(1~9층) → 서리 동굴(10~19층, 얼음물) →
  불씨 심층(20~30층, 용암). 바위 하나 밑에 숨은 **사다리**를 찾아 내려가고, 5층마다 입구의 **승강기**가 열림.
  어둠 속에서는 랜턴·횃불·수정·빛나는 버섯·용암 불빛만이 길을 비춤. 깊을수록 철과 귀한 보석이 많이 나옴.
- **온실**: 농장 북동쪽의 낡은 유리 온실을 복원하면(4,000G·나무·돌·구리/철 주괴) 7×4칸에서 서리·비·계절에 상관없이
  어떤 작물이든 기를 수 있음. 밤엔 온실 조명등이 켜짐.
- **거대 작물**: 호박·수박·양배추·콜리플라워·멜론 등을 3×3으로 키우면 밤사이 하나의 거대 작물로 합쳐지기도 함 (수확 14~20개).
- **가공·자동화**: 과일 → 잼·과일주, 채소 → 절임·주스, 허브 → 차, 광석 → 주괴, 섬유·작물 → 비료, 작물 → 씨앗.
  벌통은 근처에 핀 꽃(라벤더·해바라기…)에 따라 다른 꽃꿀을 만들고, **자동 수확기**는 매일 아침 5×5 칸을 대신 수확.
  가공품은 작물마다 별개의 상품(예: 딸기 잼, 사과 과일주)으로 원재료보다 훨씬 비싸게 팔림.
- **사계절 풍경**: 봄 꽃잔디, 여름 초록, 가을 단풍과 낙엽, 겨울 눈밭·얼어붙은 연못·지붕 위 눈과 고드름.
- **실시간 조명**: 해가 동쪽에서 떠 서쪽으로 지며 모든 나무·건물·사람이 자기 모양 그대로의 그림자를 드리움
  (아침엔 길게 왼쪽, 한낮엔 짧게, 해질녘엔 길게 오른쪽, 맑은 밤엔 희미한 달그림자). 골든아워 색보정, 햇빛·달빛에 따라
  달라지는 물 반짝임, 수면에 흔들리는 등불 반사, 2×2 격자에 디더링으로 번지는 도트 조명.
- **낭만적인 연출**: 가로등·창문 불빛, 회전하는 등대 빛줄기, 구름 그림자, 벚꽃잎·낙엽·반딧불이, 비·폭풍·안개·눈.
- **항해 일지 UI**: 하늘 다이얼(시간·날씨·기온·출항 카운트다운), 로프 핫바, **끌어서 옮기는 가방**(절반 나누기·핫바 지정),
  일지(나의 섬 현황·섬 주민 호감도와 좋아하는 선물·작물 도감 200종·출하 기록), 확대·이동되는 **섬 지도**(명소·주민 위치).
  8비트 비트맵 폰트(Galmuri)로 글자가 깨지지 않음.
- **캐릭터 커스터마이즈**: 16×32 레이어 도트 — 머리 모양 10·머리색 12·눈 모양 4·눈동자 6·피부 8·상의 8·하의 3·신발·모자 7·
  장신구(안경·주근깨·목도리), 8프레임 걷기. 손에 든 물건은 종류별로 실제로 들고 다님(도구는 손에, 작물은 두 손으로 앞에, 설치물은 머리 위로).
- **6개 언어**: 한국어·영어(미국/영국)·일본어·독일어·스페인어. 대사·아이템·작물 200종까지 모두 번역.
- **설정**: 언어, 12/24시간 시계, °C/°F, 대사 속도, 전체 화면, 화면 확대, 정수 배율, 프레임 제한, 음량 4종,
  **키 재설정**, 번개 번쩍임 끄기, 큰 커서, 항상 달리기.
- **안전한 저장**: 30초마다 자동 저장 + 메뉴를 열 때·창을 내릴 때·종료할 때 저장. 데스크톱 앱은 운영체제 표준 위치에 파일로 저장
  (Windows `%APPDATA%\LuminaIsle\Saves`, macOS `~/Library/Application Support/LuminaIsle/Saves`,
  Linux `~/.local/share/LuminaIsle/Saves`) — 임시 파일에 쓰고 디스크에 기록한 뒤 교체하며 이전 저장은 `.bak`으로 보관.
- **사운드**: 실제 녹음 샘플로 하나씩 제작한 효과음 33개·환경음 6개. **직접 작곡·편곡한 음악 9곡** —
  봄·여름·가을·겨울 낮 테마, 저녁, 밤, 비, 광산, 타이틀. 곡마다 2~3분 반 길이로 인트로·A·B·브리지를 오가며
  기타·하프·피아노·플루트·오보에·틴 휘슬·첼로·현악·마림바·칼림바 등 실제 악기 샘플이 차례로 들어오고 빠짐.

## 실행

```bash
npm install
npm run app          # 데스크톱 앱으로 실행 (Electron)
npm run app:dist     # 설치 파일 만들기 → packages/desktop/release (Windows·macOS·Linux)
npm run dev          # 브라우저 개발 모드 http://localhost:5173
```

- 이동 `WASD` · 달리기 `Shift` · 도구 사용 `좌클릭/Space`(누르고 있으면 연속) · 상호작용·대화·수확 `우클릭/F`
- 가방 `E` · 일지 `Tab` · 지도 `M` · 메뉴 `Esc` · 핫바 `1~0`/휠 · 전체화면 `F11`/`Alt+Enter` (모든 키는 설정에서 바꿀 수 있음)
- 선물: 작물·채집물을 들고 주민에게 사용 · 잠은 19시 이후 침대에서
- 광산: 채석장 동굴 입구에서 `F` → 곡괭이로 바위 캐기 → 사다리에서 `F`로 오르내리기
- 개발 모드 전용 키: `F1` 날씨 변경, `F2` 1시간 경과, `F3` 작물 다 자라기, `F4` 골드 +5000

```bash
npm run check        # 타입체크 + 단위 테스트
npm run build        # 배포용 빌드 → packages/client/dist
npm run audio        # 사운드 에셋 다시 제작 → packages/client/public/audio
```

## 구조 (모듈 · 서버 · 클라이언트)

```
packages/core     @lumina/core    순수 규칙·데이터 (작물 200종, 섬 생성, 날씨, 생장, 경제, 프로토콜, 번역 표)
packages/server   @lumina/server  권한 있는 시뮬레이션 (Web Worker / Node WebSocket, 세이브)
packages/client   @lumina/client  픽셀 렌더러, UI, 입력, 오디오 재생, 씬
packages/desktop  @lumina/desktop 데스크톱 앱 (Electron, app:// 로 빌드 결과 제공)
tools/audio                       사운드 제작 도구 (녹음 샘플 → 편집 → OGG)
tools/i18n                        번역 대상 문구 추출 (테스트가 6개 언어 누락을 검사)
tools/font                        Galmuri BDF → 비트맵 글꼴 (일본어 한자는 별도 파일로 필요할 때만 로드)
docs/design                       설계도
```

자세한 내용은 [설계도](docs/design/README.md)를 참고하세요.
