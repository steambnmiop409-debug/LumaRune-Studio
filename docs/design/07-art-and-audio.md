# 07. 아트 · 사운드 디렉션

## 1. 해상도와 스케일

- 논리 해상도 **640×360**(16:9). 창 크기에 맞춰 **정수 배율**(1080p = ×3, 1440p = ×4)로 확대하고,
  남는 공간은 시야를 넓혀 채운다(검은 띠 없음).
- 타일 16×16, 캐릭터 **16×32**(스타듀 밸리와 같은 비율, 머리가 큰 약 2.3등신), 나무 32×48, 건물 48~96px.
- 카메라는 정수 픽셀에 스냅. 이미지 스무딩 비활성화.

## 2. 팔레트와 색 규칙

- 공용 팔레트(`client/src/art/palette.ts`)에서만 색을 고른다.
- **휴 시프팅**: 그림자는 명도 −, 색상 → 파랑/보라 방향. 하이라이트는 명도 +, 색상 → 노랑 방향.
- **외곽선**: 순수 검정 금지. 대상 색의 가장 어두운 동색 계열(`shade(color, 3)`)로 자동 생성.
- 낭만 톤: 채도를 한 단계 낮춘 파스텔 + 노을 산호·등대 호박색을 포인트로.

## 3. 절차적 아트 생성기 (프로토타입 → 수작업 아트 교체 가능)

작물 200종 × 5단계, 캐릭터 조합 수만 가지를 초기에 전부 손으로 그릴 수 없으므로,
**규칙 기반 픽셀 스프라이트 생성기**로 시작하고, 이후 Aseprite 수작업 스프라이트로 하나씩 교체한다.
교체는 `SpriteRegistry`에 같은 키로 이미지를 등록하면 끝나도록 설계한다.

| 대상 | 생성 방식 |
| --- | --- |
| 지형 | 픽셀 단위 셰이딩: 노이즈로 흔들린 경계, 풀잎·모래알 텍스처, 경계 그림자 1px |
| 물 | 수심(고도 보간) 그라데이션, 해안 거품 4프레임, 반짝임 입자 |
| 작물 | 형태(잎채소·뿌리·덩굴·관목·곡물·줄기·꽃·나무·논)×단계, 작물별 잎·열매 색 |
| 수확물 아이콘 | 형태(둥근·긴·뿌리·결구·송이·꼬투리·꽃·다발·고추·박·구근·잎·견과·열매) |
| 캐릭터 | **한 픽셀씩 찍은 레이어 템플릿**(머리·헤어 6종·상의 4종·팔·다리 프레임·모자 3종) + 재질별 4단계 색 램프로 팔레트 스왑 (아래 8절) |
| 건물 | 벽·지붕·창문·문·간판 조립, 밤에는 창문 발광 레이어 |

## 4. 조명과 시간대

| 시각 | 색보정(곱하기) | 비고 |
| --- | --- | --- |
| 05:00 | 짙은 남색 `#39406e` | 여명 전 |
| 06:30 | 분홍 새벽 `#e8b4a8` | 새소리 시작 |
| 09:00 | 흰색 `#ffffff` | 기준 |
| 16:30 | 금빛 `#ffe6b8` | 골든아워 |

| 21:00 ~ | 밤 `#4a5288` | 반딧불이·별빛 수면 |

- 흐림/비/폭풍은 색보정에 회청색을 섞고 채도를 낮춘다. 눈 오는 날은 밝고 차갑게.
- **해의 위치** (`render/Lighting.ts` `sunAt`): 해는 동쪽(화면 오른쪽)에서 떠서 머리 위를 지나 서쪽으로 진다.
  나무·건물·소품·작물·사람은 자기 모양 그대로의 실루엣을 해 반대쪽으로 기울여 땅에 눕힌 **투영 그림자**를 드리운다 —
  아침엔 왼쪽으로 길게, 한낮엔 짧게, 해질녘엔 오른쪽으로 길게. 그림자는 한 레이어에 모아 한 번에 곱해서 겹쳐도 진해지지 않는다.
  흐리면 옅어지고 비·폭풍엔 사라지며(대신 부드러운 캐노피 그림자), 맑은 밤엔 달빛이 희미한 푸른 그림자를 만든다.
- **조명 격자**: 광원(가로등·창문·모닥불·등대·온실 조명등·랜턴·반딧불이·버섯)은 2×2 픽셀 격자 위에서 더해진 뒤
  몇 단계의 밝기로 나뉘고 4×4 순서 디더링으로 이어진다 — 불빛이 매끈한 에어브러시가 아니라 도트 고리로 번진다.
  그 결과를 씬에 곱하고, 같은 격자 빛을 약하게 더해 도트 블룸을 만든다.
- **색보정 패스**: 골든아워엔 따뜻한 소프트라이트, 맑은 한낮엔 약간의 대비, 밤엔 채도를 낮추고 비네트를 깊게.
- **물빛**: 수면 반짝임은 해가 강할수록 많고 밝으며(해질녘엔 금빛, 달밤엔 은빛), 물가의 등불은 흔들리는 반사 줄무늬를 수면에 늘어뜨린다.
- **등대 빛줄기**: 밤에 바다 위를 천천히 회전하는 원뿔형 빛. 섬의 상징.
- **광산**: 하늘빛이 없다. 층마다 어두운 테마 색 위에 플레이어 랜턴(깜박임), 벽 횃불, 수정, 빛나는 버섯, 용암,
  사다리 구멍으로 새어 드는 햇빛(밤엔 달빛)만이 같은 조명 격자로 비춘다.

## 5. 환경 생명감

- 바람 세기에 연동된 나무·풀 흔들림(수관만 1px 오프셋).
- 구름 그림자가 바람 방향으로 섬 위를 천천히 지나감.
- 계절 입자: 봄 벚꽃잎, 여름 밤 반딧불이, 가을 낙엽, 겨울 눈.
- 해변 갈매기, 굴뚝 연기, 풍차 회전, 부두의 출렁이는 배.
- 비: 기울어진 빗줄기, 지면 튐, 어두워지는 지면. 폭풍: 번개 섬광 + 천둥 지연음.

## 6. 애니메이션 손맛

- 도구: 예비 동작(2프레임) → 휘두르기 → 흙/물 파티클 → 복귀.
- 수확: 작물이 위로 "톡" 튀었다가 캐릭터에게 빨려 들어감 + 품질 별 반짝임.
- 걷기: 4프레임, 발밑 먼지(흙길), 물 튐(비 오는 날).
- 상자 운반: 머리 위 상자가 걸음마다 1px 흔들림.

## 7. 사운드 — 실제 녹음 샘플로 하나씩 제작

런타임에 코드로 소리를 합성하지 않는다. 모든 효과음·환경음·음악은 **오디오 파일(OGG)** 이며,
`tools/audio`의 제작 도구로 하나씩 만든다 (`npm run audio`).

- **원재료**: GeneralUser GS 사운드폰트의 **실제 녹음 샘플** — GS 효과음 키트(발소리, 문, 풍경,
  새소리, 빗소리, 천둥, 바람, 파도, 시냇물, 물방울)와 실제 악기(하프, 뮤직박스, 나일론 기타, 플루트,
  피아노, 첼로, 현악, 튜바, 호른, 마림바, 칼림바, 튜블러 벨 등).
- **제작 과정**: 샘플을 렌더링 → 겹치기(레이어링) → 잘라내기(발소리 단발 추출) → 피치 변주 →
  EQ/필터 → 페이드 → 루프 크로스페이드(환경음) → 음량 정규화 → OGG 인코딩.
- **레시피**: 효과음마다 무엇을 어떻게 섞었는지 `tools/audio/src/sfx.ts`에 주석으로 기록.

| 분류 | 파일 | 설계 |
| --- | --- | --- |
| 발소리 | step_grass ×4, step_path ×4, step_wood ×3 | 녹음된 발소리 + 셰이커(풀 스침)/마라카스(자갈)/우드블록(나무 판자) |
| 농사 | hoe ×3, water, refill, plant, fert | 킥 드럼 둔탁음 + 발소리 크런치 + 흙 긁힘 / 시냇물 + 물방울 / 브러시 탭 / 카바사 흩뿌림 |
| 수확 | harvest ×2, pop ×3, sparkle | 칼림바+피치카토 / 하이 우드블록 가속 / 첼레스타 |
| 경제·항구 | coin, crate, horn, bell | 뮤직박스 2음 / 문 쿵 소리 + 로우 톰 / 튜바·호른·바순 뱃고동 / 튜블러 벨 |
| UI | click, open, close, error, door, chime | 림 클릭 / 하프 상행·하행 / 마림바 / 문 삐걱 + 가게 종 / 녹음된 윈드차임 |
| 환경음(루프) | sea, rain, wind, stream, birds, crickets | 녹음 루프를 길게 유지 후 이음새 없이 크로스페이드 |
| 음악(직접 작곡·편곡) | title, spring, summer, autumn, winter, evening, night, rain, mine | 아래 표 |

곡은 코드 기호와 손으로 쓴 선율로 된 **구간**(인트로 · A · A′ · B · 브리지 · 아웃트로)으로 짜여 있고, 구간마다
악기가 들어오고 빠지며 선율을 주고받는다(`tools/audio/src/music.ts`). 반주는 코드에서 만들어진다 — 가까운 음으로
이어지는 보이싱의 현악 패드, 분산화음, 핑거피킹(근음·5음 교대 베이스), 경과음이 붙는 베이스, 3도·7도로 움직이는
내성부, 피치카토·스트럼 스탭, 브러시 드럼 그루브. 브리지에서는 주제 선율을 두 배로 늘여(확대) 다른 악기가 천천히 다시 부른다.
