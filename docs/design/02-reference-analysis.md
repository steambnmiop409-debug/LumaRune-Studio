# 02. 레퍼런스 분석 — 고퀄리티 픽셀 게임의 원리

상업적으로 성공했고 픽셀아트 품질로 평가받는 게임들을 **UI**, **아트**, **연출** 관점에서 분석하고,
우리가 가져올 원리와 피할 점을 정리한다. (분석은 공개된 플레이 경험 기준)

## 1. 게임별 분석

### Stardew Valley (2016) — 장르의 기준점
- **아트**: 16×16 타일, 캐릭터 16×32, 화면 4배 확대. 채도 높은 팔레트, 계절마다 타일셋 교체.
- **UI**: 하단 핫바(12칸), 우상단 시계(날짜·시간·날씨·계절 아이콘)와 돈, 우하단 체력 바.
  나무 판자 테두리 메뉴, 탭으로 나뉜 인벤토리.
- **잘한 점**: 필요한 정보가 항상 같은 자리에 있음. 대상 타일 하이라이트로 도구 사용이 명확함.
- **아쉬운 점**: 작은 글씨, 정보 밀도가 높은 탭 메뉴, 날씨 예보가 TV로만 확인됨,
  씨앗을 사기 전에 재배 조건을 알기 어려움.
- **가져올 것**: 고정된 HUD 위치, 대상 타일 커서, 하루 정산 화면.

### Fields of Mistria (2024, 앞서 해보기) — 부드러운 현대적 픽셀
- **아트**: 애니메이션 풍 캐릭터, 파스텔 톤, 외곽선을 어두운 동색 계열로 처리해 부드러움.
- **UI**: 둥근 모서리 패널, 넓은 여백, 큰 글씨. 스타듀보다 "읽기 편한" 방향.
- **가져올 것**: 여백과 가독성, 동색 계열 외곽선(검정 외곽선 대신 색이 있는 외곽선).

### Eastward (2021) — 밀도 높은 수작업 픽셀 + 조명
- **아트**: 매우 높은 디테일의 배경, 생활감 있는 소품 배치(간판, 빨래줄, 화분).
- **연출**: 동적 조명과 그림자, 영화적 구도, 환경 애니메이션(연기, 깜빡이는 간판).
- **가져올 것**: *생활감 있는 소품 배치*, 창문 불빛, 환경 애니메이션.

### Sea of Stars (2023) — 픽셀아트에 실시간 조명
- **연출**: 낮·밤 전환 시 광원 방향과 색이 바뀌고, 물 반사와 그림자가 픽셀아트 위에서 동작.
- **UI**: 최소한의 HUD, 상황에 맞는 프롬프트.
- **가져올 것**: 시간대별 색보정(LUT 개념), 광원 합성, 물 표면 반짝임.

### Octopath Traveler (2018) — HD-2D
- 픽셀 스프라이트에 블룸·피사계 심도·틸트시프트 같은 **후처리**를 얹어 고급스러움을 만든다.
- **가져올 것**: 광원 블룸(가산 합성 글로우), 비네팅. 단, 픽셀 선명도는 해치지 않는 선에서.

### Hyper Light Drifter (2016) — 절제된 팔레트
- 마젠타·청록 중심의 제한된 팔레트, 그림자는 차갑게·하이라이트는 따뜻하게(**휴 시프팅**).
- UI 텍스트가 거의 없고 시각 언어로 전달.
- **가져올 것**: 휴 시프팅 규칙, 아이콘 중심의 정보 전달.

### Kingdom Two Crowns — HUD 없는 분위기
- 수면 반사, 안개, 날씨 조명만으로 분위기를 만든다. HUD를 최소화해 풍경을 주인공으로.
- **가져올 것**: 풍경을 가리지 않는 HUD, 날씨가 곧 색감.

### Moonlighter (2018) — 상점 경영 UI
- 가격을 매기고 손님 반응을 노트에 기록하는 UI. 시장 정보를 *기록해 가는* 재미.
- **가져올 것**: 시세 수첩(출하 기록과 시세 변동을 일지에 남김).

### Celeste / Owlboy — 애니메이션과 손맛
- 스쿼시&스트레치, 예비 동작, 먼지 파티클, 짧은 히트스톱. 작은 스프라이트도 생동감 있게.
- **가져올 것**: 수확 시 작물 "톡" 튀어오르는 연출, 도구 휘두르기 예비 동작, 발자국 먼지.

## 2. 고퀄리티 픽셀아트의 공통 원리

| 원리 | 설명 | 루미나 아일 적용 |
| --- | --- | --- |
| 픽셀 밀도 일관성 | 한 화면에서 픽셀 크기가 섞이지 않음(mixel 금지) | 월드·UI 모두 동일한 논리 해상도에서 그림, 정수배 확대 |
| 정수 배율 | 1픽셀이 화면 N×N으로 정확히 확대 | 640×360 기준, 창 크기에 맞춰 정수 배율 + 가변 시야 |
| 제한 팔레트 + 휴 시프팅 | 그림자는 파랑/보라 쪽, 하이라이트는 노랑 쪽으로 | 공용 팔레트 모듈, 작물 색도 팔레트 규칙으로 생성 |
| 실루엣 가독성 | 상호작용 대상은 윤곽·명도 대비가 뚜렷 | 수확 가능한 작물은 열매가 튀는 색 + 반짝임 |
| 조명이 곧 분위기 | 스프라이트를 다시 그리지 않고 광원·색보정으로 시간대 표현 | 곱하기 합성 색보정 + 가산 합성 광원 |
| 환경 생명감 | 흔들리는 풀, 파도, 새, 구름 그림자, 파티클 | 바람 세기에 연동된 나무 흔들림, 구름 그림자, 반딧불이 |
| 손맛 | 입력→반응이 즉각적이고 과장됨 | 도구 애니메이션, 흙 파티클, 사운드, 숫자 팝업 |
| 일관된 외곽선 규칙 | 검정 대신 동색 계열의 어두운 외곽선 | 스프라이트 생성기에서 자동 외곽선(색상 기반) |

## 3. 피할 점

- 작은 글씨·빽빽한 탭 메뉴 → 기본 글꼴 12px(한글 픽셀 폰트), 한 화면 한 목적.
- 정보가 숨겨진 시스템(날씨·재배 조건) → 하늘 다이얼, 씨앗 봉투 카드로 항상 노출.
- 비정수 확대로 인한 흐림/지글거림 → 카메라 좌표 픽셀 스냅, 이미지 스무딩 끔.
- 풍경을 가리는 HUD → HUD는 화면 가장자리, 반투명 없이 작고 단단하게.
