# 03. UI/UX 설계 — "항해 일지" 아이덴티티

## 1. 콘셉트

섬과 바다, 등대, 화물선이라는 세계관에서 출발해 UI 전체를 **선원의 항해 일지(양피지·잉크)**와
**황동 계기판(나침반·육분의)**으로 통일한다. 나무 판자(스타듀), 둥근 파스텔 패널(미스트리아)과
구별되는 루미나 아일만의 얼굴이다.

| 요소 | 모티프 | 색 |
| --- | --- | --- |
| 패널 바탕 | 누렇게 바랜 일지 종이, 미세한 종이 결 | 양피지 `#f3e3c3` / 그림자 `#d9c29a` |
| 테두리 | 잉크 선 1px + 황동 리벳 모서리 | 잉크 네이비 `#2b2d4a`, 황동 `#c89b52` |
| 강조 | 바다색 리본, 산호색 경고 | 청록 `#4fa3a5`, 산호 `#e8836b` |
| 글꼴 | 갈무리11(본문), 갈무리9(보조), 갈무리11 Bold(제목) | 잉크 네이비 |

## 2. HUD 배치 (640×360 기준, 가장자리 고정)

```
┌──────────────────────────────────────────────────────────────┐
│ [편지 토스트]                                  ╭─하늘 다이얼─╮│
│                                                │ ☀ 06:40    ││
│                                                │ 봄 3일(화) ││
│                                                │ 14°C  맑음 ││
│                                                ╰────────────╯│
│                                                [⚓ 출항 3:20]│
│                                                [💰 1,240 G ]│
│                     (월드)                                   │
│                  [E] 씨앗 상점 ← 상황 프롬프트                 │
│                                                              │
│ [체력 잎]   ┌─┬─┬─┬─┬─┬─┬─┬─┬─┬─┐   [들고 있는 상자]          │
│             └─┴─┴─┴─┴─┴─┴─┴─┴─┴─┘ ← 로프로 묶은 핫바          │
└──────────────────────────────────────────────────────────────┘
```

### 2.1 하늘 다이얼 (Sky Dial) — 시그니처 HUD
- 반원형 창 안에 **실제 하늘 그라데이션**이 시간에 따라 변하고, 해/달이 호를 따라 이동한다.
- 날씨가 창 안에 그대로 그려진다(구름이 흐르고, 비가 내리고, 눈이 온다).
- 아래 줄: 날짜·요일, 시간(10분 단위), 기온, 날씨 이름.
- 그 아래 **출항 칩**: 출항까지 남은 시간. 1시간 전부터 황동색으로 깜빡이고 종소리.
- 내일 날씨 예보는 다이얼을 가리키면(마우스 오버) 보인다 → 비 대비 계획이 가능.

### 2.2 로프 핫바
- 10칸, 칸 사이를 로프 매듭이 잇는다. 선택된 칸은 2px 위로 떠오르고 황동 테두리.
- 칸을 바꾸면 핫바 위에 아이템 이름표가 1.2초간 표시.
- 물뿌리개는 칸 하단에 물 게이지 표시.

### 2.3 상황 프롬프트 (Whisper Prompt)
- 상호작용 가능한 대상 근처에서만 머리 위에 작은 말풍선: `[E] 씨앗 상점 들어가기`.
- 키 글리프는 키캡 모양 스프라이트, 게임패드 연결 시 버튼 글리프로 교체.

### 2.4 대상 타일 커서
- 행동할 타일에 모서리 괄호 4개가 숨쉬듯 움직인다.
- 색: 가능(잉크), 불가능(산호), 수확 가능(황동 + 반짝임).

### 2.5 작물 살펴보기 말풍선
- 심은 작물을 가리키면: 이름, **생장 링**(진행률), 물 상태(물방울), 스트레스 아이콘
  (비 과다·가뭄·추위·더위), 예상 품질 ★.

## 3. 메뉴 — "항해 일지" 책

`Tab`/`I`로 여는 펼친 책. 오른쪽 가장자리에 **책갈피 리본 탭**.

| 책갈피 | 왼쪽 페이지 | 오른쪽 페이지 |
| --- | --- | --- |
| 가방 | 30칸 인벤토리 그리드 | 선택 아이템 카드 + 캐릭터 미리보기 |
| 작물 도감 | 200종 목록(발견/미발견 실루엣, 분류 필터) | 씨앗 봉투 카드(재배 조건 전부) |
| 출하 기록 | 날짜별 출하 내역 | 작물별 시세 변동 그래프(시세 수첩) |
| 섬 지도 | 섬 전체 미니맵, 현재 위치, 상점 아이콘 | 구역 설명 |
| 설정 | 음량, 화면 배율, 조작키 | |

## 4. 씨앗 봉투 카드 (Seed Packet Card)

실제 씨앗 봉투 디자인을 차용. 상점·도감·툴팁 모두 같은 카드를 쓴다.

```
╭──────────────────────────╮
│ [작물 그림]   토마토       │
│              Tomato      │
│ 등급 ●●○○○   열매채소     │
├──────────────────────────┤
│ 🌡 18~29°C   ⏳ 13일(+4일) │
│ 💧 ●●○   ☂ 비에 약함!      │
│ ❄ 서리에 약함  🪜 지지대   │
│ 수확 2~3개   판매 ~120G    │
╰──────────────────────────╯
```

## 5. 상점 UX

- 상점 주인 초상 + 한 줄 대사(시간·날씨에 따라 변함).
- 왼쪽: 품목 목록(현재 기온에 맞는 씨앗이 위로, "지금 심기 좋아요" 리본).
- 오른쪽: 씨앗 봉투 카드, 수량 선택(−/+, Shift=×10), 총액, 구매.
- 돈이 부족하면 구매 버튼이 산호색으로 흔들리고 사유 표시.

## 6. 포장대 · 출하 UX

- 포장대 UI: 가방의 작물이 품질별로 묶여 보이고, 한 번에 한 상자(최대 30개, 같은 작물·품질).
- 상자를 포장하면 캐릭터가 **머리 위로 상자를 든다**(이동속도 80%). 핫바 옆에 상자 내용 표시.
- 배 앞에서 `[E] 상자 싣기` → 선원이 받아 드는 연출, 적재 목록 갱신.
- 17:00 출항: 뱃고동 → 배가 수평선으로 떠남 → **정산 편지** 토스트(작물별 수량×단가×품질).

## 7. 하루 마무리 화면 ("오늘의 항해 일지")

잠자리에 들면 별이 흐르는 화면 위로 일지가 펼쳐지고, 오늘 출하 수익이 한 줄씩 적힌다.
합계는 숫자가 굴러가며 올라간다. 내일 날씨 예보와 함께 페이드 인.

## 8. 첫 접속 — 캐릭터 만들기

- 좌측: 큰 미리보기(4방향 회전, 걷기 애니메이션 재생).
- 우측: 이름, 농장 이름, 피부색(8), 헤어스타일(8), 머리색(10), 눈 색(6),
  상의 스타일(4)·색(12), 하의 색(10), 모자(5), 스카프 색. 무작위 버튼.
- 항목을 바꾸면 미리보기 캐릭터가 작게 "폴짝" 반응.

## 9. 조작

| 행동 | 키보드/마우스 | 게임패드(예정) |
| --- | --- | --- |
| 이동 | WASD / 방향키 | 왼쪽 스틱 |
| 도구 사용 | 좌클릭 / Space | X |
| 상호작용·수확 | 우클릭 / E | A |
| 핫바 | 1~0, 휠 | LB/RB |
| 일지 | Tab / I | Y |
| 지도 | M | 뷰 버튼 |

## 10. 접근성

- 글꼴 최소 10px(논리 해상도), 중요 정보는 색+아이콘 이중 표기(색약 대응).
- 화면 흔들림·번쩍임(번개) 끄기 옵션, 텍스트 속도 옵션, 키 재배치.
