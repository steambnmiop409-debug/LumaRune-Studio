## 한 장 요약

- **핵심 사이클**: 씨앗 상점에서 씨앗 구매 → 밭 갈기·심기 → 물·영양 관리(날씨 대응) → 수확 →
  포장대에서 **출하 상자**에 담기 → 상자를 직접 들고 **부두의 배**까지 운반 → 17:00 출항 시 정산 →
  번 돈으로 더 좋은 씨앗·스프링클러·영양제 구매.
- **현실적인 농사**: 실제 작물 200종. 온도 범위, 물 요구량, **비 내성**(비를 많이 맞으면 갈라지고
  썩는 작물), 서리 내성, 덩굴 지지대, 다년생 여부가 모두 다르다.
- **낭만적인 섬**: 등대 빛줄기가 도는 밤바다, 노을빛 색보정, 구름 그림자, 반딧불이, 벚꽃잎, 비·폭풍·안개·눈.
- **고유 UI**: 선원의 항해 일지와 황동 계기판을 모티프로 한 UI. 하늘 다이얼(시간·날씨·기온·출항
  카운트다운), 씨앗 봉투 카드, 작물 도감 200종.
- **구조**: `@lumina/core`(순수 규칙·데이터) · `@lumina/server`(권한 있는 시뮬레이션, 워커/Node) ·
  `@lumina/client`(렌더링·UI·입력·사운드). 싱글플레이도 내장 서버(Web Worker)로 돌아가므로
  멀티플레이 전환이 쉽다.
