# 08. 로드맵 · 스팀 출시

## 마일스톤

| 단계 | 목표 | 주요 산출물 |
| --- | --- | --- |
| **M0 기반** (현재) | 설계도 + 모노레포 + 핵심 루프가 도는 버티컬 슬라이스 | 설계 문서, core/server/client, 섬 생성, 작물 200종 데이터, 시간·날씨·조명, 상점, 포장·운반·출항, 캐릭터 만들기, 저장 |

| M6 협동 | 1~4인 온라인 협동 | 전용 서버/호스트, 스팀 로비 |

## 스팀 출시 체크리스트

- [ ] Windows/macOS/Linux 빌드 (Electron), Steam Deck 호환(1280×800 → 논리 해상도 가변 시야로 대응)
- [ ] 게임패드 전 기능 지원, 버튼 글리프 자동 교체
- [ ] 해상도·창모드·배율·V-Sync·음량·키 재배치 설정
- [ ] 스팀 클라우드 세이브, 업적 30개 이상, 리치 프레즌스("봄 3일 · 토마토 수확 중")
- [ ] 한국어/영어/일본어 현지화 (문자열 테이블 분리)
- [ ] 크래시 로그 수집, 세이브 백업·복구
- [ ] 스토어 에셋: 캡슐 이미지 5종, 스크린샷 5장+, 트레일러
- [ ] 연령 등급 설문, 가격 정책, 지역 가격
- [ ] 폰트 라이선스(Galmuri OFL) 고지, 서드파티 라이선스 목록

## 품질 기준 (모든 단계 공통)

1. 60fps 유지(통합 그래픽 노트북 기준), 입력 지연 1프레임 이내.
2. 픽셀이 뭉개지거나 크기가 섞인 화면이 한 장도 없을 것.
3. 모든 행동에 시각+청각 피드백.
4. 세이브 손상 0: 저장은 원자적(임시 파일 → 교체), 이전 세이브 1개 보관.
5. core 규칙은 단위 테스트로 보호, CI 통과 없이는 병합하지 않음.
