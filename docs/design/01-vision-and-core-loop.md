# 01. 비전과 핵심 루프

## 1. 한 문장 비전

**"하루의 끝, 노을 속으로 떠나는 배에 내가 기른 작물 상자를 싣는 순간의 뿌듯함."**

루미나 아일은 경쟁·전투가 아닌 *돌봄과 계절의 리듬*을 다루는 게임이다. 플레이어는 등대가 있는
작은 섬에 도착해 버려진 밭을 일구고, 매일 저녁 출항하는 화물선에 작물을 실어 보내며 섬의 삶을
꾸려 간다.

## 2. 플레이어가 느껴야 할 감정

| 순간 | 감정 | 이를 만드는 장치 |
| --- | --- | --- |
| 아침 | 설렘 | 새벽 분홍빛 색보정, 새소리, 하늘 다이얼의 일기예보 |
| 한낮 | 몰입 | 밭일의 손맛(도구 애니메이션·파티클·사운드), 작물 상태가 한눈에 보임 |
| 비 오는 날 | 긴장과 아늑함 | 비에 약한 작물은 비가림막 필요, 빗소리, 젖은 땅 색 |
| 노을 | 뿌듯함 | 상자를 들고 부두로 걷기, 출항 뱃고동, 정산 금액 롤링 |
| 밤 | 낭만 | 등대 빛줄기, 가로등, 반딧불이, 별빛 반짝이는 수면 |

## 3. 핵심 사이클 (Core Loop)

```
 ┌────────── 씨앗 상점(들꽃 씨앗방) ◀──────────────┐
 │  계절·기온에 맞는 씨앗 구매                       │
 ▼                                                 │
 밭 갈기(괭이) → 심기 → 물주기/스프링클러 → 영양제   │ 수익으로
 │           ▲ 날씨 대응: 비가림막·배수·서리 대비     │ 업그레이드
 ▼                                                 │
 수확(낫/손) → 품질 ★1~5 결정                       │
 ▼                                                 │
 포장대: 같은 작물·품질끼리 출하 상자에 담기          │
 ▼                                                 │
 상자를 들고 부두까지 운반(들고 있으면 이동속도 감소)  │
 ▼                                                 │
 화물선에 적재 → 17:00 출항 → 시세×품질로 정산 ────────┘
         └─ 도구 공방(등불 공방): 물뿌리개·스프링클러·영양제·비가림막·손수레
```

### 사이클 설계 의도
- **상자를 직접 옮기는 행위**가 게임의 시그니처다. 스타듀 밸리의 "출하함에 넣으면 끝"과 달리,
  포장 → 운반 → 적재라는 물리적인 과정이 하루의 마무리 의식이 된다.
- 운반은 번거로움이 아니라 *선택*이 되도록: 한 상자 30개, 손수레 업그레이드 시 4상자.
  밭–부두 거리는 걸어서 약 15초로, 가는 길에 마을·바다 풍경을 지나게 배치한다.
- 배는 매일 **17:00 출항**. 놓치면 다음 날. 하늘 다이얼에 출항 카운트다운이 표시된다.

## 4. 현실성 원칙

1. **작물은 실제 작물 200종**으로 시작한다. 이름·특성은 실제 재배 특성을 게임 스케일로 옮긴다.
2. **계절은 기온으로 표현**한다. "봄 작물"을 하드코딩하지 않고, 매일의 기온이 작물의 적정 온도
   범위에 들어오는지로 생장이 결정된다. 서리(0°C 미만)는 내한성 없는 작물을 죽인다.
3. **비는 공짜 물이 아니다.** 비는 밭을 적시지만, 토마토·딸기·체리·포도처럼 비에 약한 작물은
   오래 맞으면 열과(갈라짐)·잿빛곰팡이로 품질이 떨어지고 결국 썩는다. 반대로 벼·미나리·연근 같은
   작물은 비를 좋아한다.
4. **시세는 움직인다.** 같은 작물을 한꺼번에 많이 팔면 값이 내려가고, 매일 조금씩 회복한다.
   제철이 아닌 작물은 비싸다.
5. **좋은 작물은 비싸고 어렵다.** 인삼·고추냉이·사프란·샤인머스캣은 등급 5로 비싸지만
   재배 조건이 까다롭다.

## 5. 차별점 요약

| 기존 농장 게임 | 루미나 아일 |
| --- | --- |
| 출하함에 넣으면 자동 판매 | 포장 → 운반 → 배 적재 → 출항 정산 |
| 계절별 작물 고정 | 매일 기온·강수 기반 생장, 서리·폭풍 |
| 비 = 자동 물주기 | 비 내성 수치, 비가림막, 과습 스트레스 |
| 작물 수십 종 | 실제 작물 200종 + 도감 |
| 나무 판자 UI | 항해 일지·황동 계기판 UI, 하늘 다이얼 |

## 6. 대상 플레이어

- 스타듀 밸리, 필즈 오브 미스트리아, 동물의 숲을 즐긴 캐주얼·미드코어 플레이어
- 한 세션 20~60분, 하루(게임 내) = 실제 약 14분
- 한국어 우선, 영어·일본어 현지화 예정
